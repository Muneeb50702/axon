LABEL and STURDIEST survive the same NUMBER of classes and differ in
WHICH. STURDIEST is immune to every copy change and dies on the two
classes that touch view ids — including a Compose migration, which
removes them wholesale while changing nothing a user sees.

NO WEIGHTED AGGREGATE IS REPORTED. Ranking these needs how often each
drift class occurs in real app updates, which this study does not
measure. The counts above assume every class is equally likely, which
is certainly false and is stated so it cannot be mistaken for a result.
